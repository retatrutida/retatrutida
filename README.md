## Research Information

Retatrutide is an investigational triple hormone receptor agonist that targets:

- GLP-1 (Glucagon-Like Peptide-1)
- GIP (Glucose-Dependent Insulinotropic Polypeptide)
- Glucagon

It is currently being investigated in clinical research. Retatrutide is not approved for human use by regulatory authorities.
